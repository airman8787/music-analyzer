1. 読み込み

待機中
曲リスト
アルバムとしてまとめて仕上げる（リストの全曲に同じ仕上げをかけ、ZIP で保存）
各曲に、10. の「おまかせマスタリング」の設定（EQ・コンプ・リミッター・音質優先など）をそのままかけます。前後の無音はトリムします。 「全曲の音量をそろえる」では、まず各曲を仕上げ、いちばん小さく仕上がった曲（音質優先で止まった曲を含む）の音量に、ほかの曲を合わせて仕上げ直します（後から音量を下げるより、リミッターのかかりが浅くなるため）。曲の数だけ時間がかかります（3 分の曲で 1 曲 30 秒前後）。
A で表示：2.〜10. に詳しい結果を出し、編集もできる曲（1 曲）。B で比べる：A と聴き比べる曲（上のバーの A / B か X キーで切り替え）。曲名をクリックしても A で表示します。
🔒 読み込んだ自分の楽曲ファイルはこのPC内だけで処理され、外部には送信されません。
はじめかた
  1. 曲ファイルを上の枠にドロップするか「ファイルを選ぶ」で選ぶ（複数まとめて OK。1 曲目が A として表示され、残りも自動で解析されて曲リストに並びます）
  2. 結果は 2. 概要 と 3. 公開前チェック から（対処のしかたと、該当箇所の再生ボタンつき）。好きな曲を 8. 保存 しておくと、上のバーの「比較対象」で比べられ、5. のターゲットも作れます
  3. 仕上げは 10. のおまかせマスタリング：ジャンルを選んでボタンを押すと、EQ・コンプ・リミッターを自動でかけ、処理前と音量をそろえて聴き比べられます
使い方と注意点（テーマ別）
見る・聴く・比べる
  • 4. のグラフはクリックで再生、ドラッグで範囲選択（範囲のスペクトラム・ループ再生・書き出し）。拡大するとスペクトログラムをその範囲で計算し直します。操作の一覧は上のバーの「?」から。
  • 構成は似た区間に A / B / C… を付け、繰り返す区間のうち最も大きいものを「サビ候補」とします。5. と 8. の「比較範囲」でサビだけを比べられます。
  • 「試聴音量」で、原音・ラウドネス一致・各配信サービスの音量を切り替えて聴けます。1. の曲リストの「B で比べる」を押すか、音声つきで保存した曲を比較対象にすると、上のバーの A / B ボタンや X キーで、同じ位置のまま聴き比べられます（「位置：サビ同士」でサビの頭をそろえます。範囲選択のループ再生中も切り替えられます）。B のファイルは保存されず、ページを閉じると消えます。
  • チェック結果の基準は「ジャンル」で切り替えられます（目安です）。比較対象を選ぶと、リファレンスとの差もチェックします。
  • PSR（3 秒ごとのピークとショートタームラウドネスの差）は潰れ具合の目安です。曲の一番大きい区間で 8 dB を下回ると潰れて聞こえやすいとされます（Ian Shepherd の目安）。DR 値は TT DR Meter と同じ計算です。
  • 5. の「ターゲット比較」では、保存した好きな曲から作ったターゲット（許容範囲）と音色を比べ、近づけるための EQ（マッチ EQ）を提案します。再生にかけて聴き比べられます。
  • 2. の「配信コーデックを通した音」では、AAC / Opus に変換したときのピークの増加と失われる音を確かめられます（Chrome / Edge の PC 版。AAC は Windows・Mac のみ）。
ファイル・マルチチャンネル
  • WAV・AIFF・FLAC・MP3・Ogg・AAC は元のサンプルレートのまま解析します（M4A など読み取れない形式は再生環境のレートに変換）。クリップ検出が正確なのは、変換なしの WAV / AIFF / FLAC だけです。
  • 5.1ch・7.1ch なども全チャンネルを読み込みます。統合ラウドネスは LFE を除きサラウンドに +1.5 dB の重みを付け、ステレオ系の指標はダウンミックスで計算します（タブ録音はステレオのみ）。
おまかせマスタリング（10.）
  • いちばん簡単なのは、かんたん表示の「おまかせで仕上げる」：診断を見て、ジャンルを選んで「音を良くする」を押し、「仕上げた音」と「元の音」を聴き比べて保存するだけです。
  • 10. の「おまかせマスタリング」でジャンルを選んで「おまかせで仕上げる」を押すと、オート EQ → オートコンプ → リミッターで、そのジャンルの大まかな目安の音量・音色に近づけます。各段はオン・オフと強さを変えられます。
  • 処理前の音が自動で B に入り、試聴音量が「ラウドネス一致」になるので、音量差に惑わされずに聴き比べられます。「元の音に戻す」で戻せます。
  • 好きな曲に近づけたいときは、その曲を 8. に保存して 5. でターゲットにし、EQ の基準を「5. で選んだターゲット」にします。
音響・振動解析（9.）
  • 9. は測定・工業向けの機能なので、最初は隠しています（9. があった場所の「9. を表示する」で出せます）。どれも「計算」を押したときだけ動きます。
  • 騒音計（IEC 61672）・オクターブ（IEC 61260）・心理音響（ISO 532-1 ラウドネス、DIN 45692 シャープネス、ECMA-74 トーナリティ、ラフネス・変動強度のモデル推定）・フィルタと信号発生・次数解析・伝達関数・一括処理・ウォーターフォール・マーカー・レポートが使えます。
  • 音圧に関わる値は「校正」に基づきます。校正器の音を録って範囲を選び「選択範囲を校正音にする」を押すと正確になります。
保存
  • 解析結果の数値は 8. で保存できます。
  • 読み込んだ音声と信号発生器で作った音は、4. の選択範囲を WAV（24bit / 32bit float）か FLAC（24bit）で書き出せます。0 dBFS を超える部分まで残すなら 32bit float を選んでください。
  • 「トリム」を切り替えると直前の音声を自動で再解析します。保存した結果は 8. から JSON で書き出し・読み込みできます（音声は含まれません）。

おまかせで仕上げる

2 つは音量をそろえて再生しています（大きいほうが良く聞こえる錯覚を防ぐため）。X キーでも切り替えられます。
何をしているの？
  • 選んだジャンルの大まかな目安に合わせて、音色の整え（EQ）→ 音量の粒をそろえる（コンプ）→ 音割れしないように音量を上げる（リミッター）を自動でかけます。
  • 音割れの基準（トゥルーピーク）は、−14 LUFS より大きく仕上げるジャンルでは −2 dBTP、それ以外は −1 dBTP（Spotify の推奨）です。ジャンルの音量は市販曲でよく見られる傾向をもとにした目安で、実測データではありません。
  • 元の曲より良くなったかは、必ず「仕上げた音」と「元の音」を聴き比べて決めてください。細かく調整したいときは「くわしい表示」の 10. で設定を変えられます。

      マッチ EQターゲットに近づけるための EQ の提案

      ターゲットとの差（灰色の点線、1/3 オクターブで平滑化・±6 dB まで）を、少ない本数のピーキング・シェルフで近づけた EQ です（水色、適用量込み）。全体の音量差は除いています。いきなり 100% にせず、半分程度から耳で確かめてください。差が許容範囲内の帯域まで無理に合わせる必要はありません。
      低域のクレスト：120 Hz 以下だけを取り出した音の、曲の大きい区間でのピークと平均の差（3 秒ごとの中央値）。小さいほど低域が圧縮されて密、大きいほどキックのアタックが立っています。ジャンルで適正値が違うので、同じジャンルのリファレンスと比べてください。帯域のレベルは 100 Hz〜4 kHz の平均を 0 dB とした 1/6 オクターブの平均です。

      拍：立ち上がりの強さから動的計画法で拍の列を求め（Ellis 2007）、コードの変わり目と低音の立ち上がりから小節の頭を決めます。コード：拍ごとの 12 音の強さと低音を、倍音を含めたコードの型と比べ、隠れマルコフモデルでつなぎます。低音が根音以外の構成音なら「C/E」のように書きます。小節をクリックすると、その位置から再生します。TAB 譜：音符を拍の格子に合わせ、同時に鳴る音ごとに弦とフレットの候補を出し、指の広がりと手の移動が小さくなる組み合わせを選びます（弾けない音は省き、その数を表示します）。押さえ方は、標準チューニングの定番の形か、構成音と最低音から探した形です。コード譜・TAB 譜・MIDI は音の書き起こし（文字・音符のデータ）なので、タブ録音からも保存できます。いずれも自動推定です。テンションの多いコード、転調、テンポが大きく揺れる曲、打楽器や歌の大きい曲では誤りが増えます。

      上級者向けの調整（手動 EQ・M/S・リニアフェーズ・コンプ / リミッターの数値）
      
      EQ
      
      
      
        
      
      
      
      
      
      
      
      対象：左右＝両チャンネルに同じ EQ／ミッド＝中央の成分（ボーカル・ベース・キックなど）だけ／サイド＝左右に広がった成分だけ。
        リニアフェーズは、各段を前向きと後ろ向きに通して位相のずれをなくします（打楽器の前に小さな「プリリンギング」が出ることがあります）。ハイパス・ローパスはリニアフェーズにすると傾きが 2 倍になります。20 Hz 以下のカットは常に最小位相です。
      
      
      コンプ
      
      
      
        
        
        
        
      
      
      圧縮量：曲の大きい部分（上位 10%）でのゲインリダクションの目標。しきい値はこれに合わせて自動で決めます。検出は 20 ms の移動平均を 2 回通した RMS です。
      
      
      リミッター
      
      
      
        
        
      
      
      保持：ゲインを下げたまま保つ時間。低音の周期より短いと 1 周期の中でゲインが揺れて歪みます（20 ms で 25 Hz まで）。リリースは、抑えている状態が続くほど最長に近づきます。
      
    
      
    
      
    
      
      
      どこで、どれだけ抑えたか
      
      
      ■ コンプ　■ リミッター（50 ms ごとの最大のゲインリダクション）。リミッターが長く深くかかっている所は、音が潰れやすい場所です。
      
      
      音色の変化（処理前・処理後・目安）
      
      
      ― 処理前　― 処理後　▒ 目安の範囲（1/6 オクターブ・音量をそろえて表示）
      
    
      
    
      曲全体（前後の無音トリム後）に、EQ → コンプ → リミッターの順でかけます（上の「対象」の設定は使いません）。処理後の音は 2.〜8. で解析し直され、「元の音に戻す」で戻せます。書き出しは「書き出し・結合・分割」タブから。
      
      ジャンルの値は、市販曲でよく見られる音量・音色の大まかな目安です（一般的な制作上の傾向をもとにした値で、特定の調査の実測値ではありません）。好きな曲に近づけたいときは、その曲を 8. に保存して 5. でターゲットにし、EQ の基準を「5. で選んだターゲット」にしてください。
      
      マスタリングでミックスの問題（楽器同士のかぶり、ボーカルの埋もれなど）は直せません。最後は必ず耳で確かめてください。配信では大きい曲ほど音量を下げられるので、音圧を上げすぎても大きく聞こえるとは限りません（2. の表を参照）。

      音階への補正：YIN 法で求めた基本周波数を、選んだ音階の一番近い音（A4 = 440 Hz）へ寄せ、TD-PSOLA で波形を並べ直します。「速さ」は目標の音へ寄せるまでの時間で、0 ms にするとケロケロした機械的な音、大きくするとビブラートが残る自然な補正になります。歌・単音の楽器向けで、和音や伴奏の入った音では正しく動きません。グラフは元のピッチ（青）と補正後のピッチ（橙）で、縦軸は MIDI のノート番号（60 = C4、1 = 半音）です。ピッチシフト・タイムストレッチ：位相ボコーダー（ピーク周辺の位相をロック）。シフトはフォルマントも一緒に動くため、大きくずらすと声の性質が変わります。
