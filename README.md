# 楽曲アナライザ

自分の楽曲ファイル（WAV / AIFF / FLAC / MP3 / Ogg / AAC など）を読み込んで、解析と編集をするブラウザツールです。`index.html` を開くだけで動きます。音声はすべてPC内で処理されます。

元: [airman8787/tab-analyzer](https://github.com/airman8787/tab-analyzer)（MIT）。タブ録音機能を外し、ファイル専用にしました。

## 編集（10. 編集・書き出し）
- 基本編集: 切り出し・削除・無音化・無音挿入、フェードイン/アウト、ゲイン、ピーク/ラウドネスのノーマライズ
- 書き出し・結合・分割: 5. のマッチ EQ や 9. のフィルタを音に反映、WAV/FLAC 書き出し（タグ付き）、複数ファイルの結合、構成区間・マーカー・一定長・無音での分割（ZIP）
- 分離・修復・ピッチ/時間（元のツールの機能）
- コード譜は小節をダブルクリックで書き換え、TAB 譜は「手で編集する」で自由に直して保存
