# 楽曲アナライザ

自分の楽曲ファイル（WAV / AIFF / FLAC / MP3 / Ogg / AAC など）を読み込んで、解析と編集をするブラウザツールです。インストールは不要で、音声はすべてPC内で処理されます（外部には送信されません）。

**使う: https://airman8787.github.io/music-analyzer/**

`index.html` をダウンロードして、ローカルで開いても同じように使えます。

元: [airman8787/tab-analyzer](https://github.com/airman8787/tab-analyzer)（MIT）。タブ録音を外し、ファイル専用にして編集機能を足しました。

## はじめかた

1. 「1. 読み込み」の枠に音声ファイルをドロップするか、「ファイルを選ぶ」で選びます。**何曲でもまとめて入れられます。**
   - 1 曲目が A として 2.〜10. に表示され、残りの曲も順番に自動で解析されて「曲リスト」に並びます（ラウドネス・ピーク・PLR・PSR・LRA・BPM・キー・チェック結果）。
   - リストの「A で表示」（または曲名のクリック）で、その曲の詳しい結果に切り替わります。
   - 「解析した曲を 8. に保存（音声つき）」にチェックすると、解析した曲が 8. の保存一覧にも入ります。一覧は CSV で保存できます。
2. 「2. 概要」と「3. 公開前チェック」で、音圧・ダイナミクス・周波数バランスなどの結果と対処のしかたを見ます。
3. 「4. 波形」はクリックで再生、ドラッグで範囲を選べます（選んだ範囲は、編集や書き出しの対象にできます）。

## A/B 比較（2曲を聴き比べる）

1. 「1. 読み込み」の曲リストで、比べたい曲の「B で比べる」を押します。最初に 2 曲だけまとめて入れたときは、自動で A と B に入ります。
2. 上のバーの ▶ / A / B ボタン、または `X` キーで切り替えます。
3. 公平に比べるときは、試聴音量を「ラウドネス一致」にしてください（大きい音のほうが良く聞こえやすいためです）。

- 切り替えても再生位置は同じままで、前後の無音をトリムした状態で頭がそろいます。ループ再生中も切り替えられます。
- B の再生中も波形に再生位置が出て、クリックするとその位置へ移動します。
- 上のバーに「B は A より -7.5 dB」のように音量差が出ます。
- B は保存されず、ページを閉じると消えます。残したい曲は、A として読み込んで「8. 保存して比較」で保存してください。

## おまかせマスタリング（10. の最初のタブ）

ジャンルを選んで「おまかせで仕上げる」を押すと、曲全体に次の順で処理をかけます。

1. **オート EQ**：「ジャンルの目安」か「5. で選んだターゲット（好きな曲から作ったもの）」との音色の差を、最大 5 バンド・±4 dB 以内の EQ で補正します（かかり具合は % で調整）。20 Hz 以下の超低域カットもかけられます。
2. **オートコンプ**：左右連動の RMS 型コンプ。しきい値は曲の大きい部分から自動で決め、そこで約 1.5 / 2.5 / 4 dB 圧縮します（弱め / ふつう / 強め）。
3. **リミッター**：先読みリミッターで、目標の統合ラウドネス（LUFS）に合わせ、トゥルーピークを上限（既定 −1 dBTP）以下に抑えます。

| ジャンル | 目標 | コンプ | 音色の傾向（汎用の目安との差） |
|---|---|---|---|
| 配信向け | −14 LUFS | ふつう | なし |
| J-POP・ポップス | −9 LUFS | ふつう | 低域 +1・張り +0.5・高域 +1 dB |
| ロック・バンド | −9 LUFS | ふつう | 張り +1・高域 +0.5 dB |
| EDM・ダンス | −7.5 LUFS | 強め | 低域 +3・張り −0.5・高域 +1.5 dB |
| ヒップホップ・トラップ | −8 LUFS | ふつう | 低域 +3.5・高域 +0.5 dB |
| R&B・バラード | −11 LUFS | ふつう | 低域 +1.5・高域 +0.5 dB |
| アコースティック・弾き語り | −13 LUFS | 弱め | 低域 −1・高域 +0.5 dB |
| ジャズ | −14 LUFS | 弱め | 高域 −0.5 dB |
| クラシック・映画音楽 | −18 LUFS | なし | 高域 −1 dB |

- ジャンルの値は、市販曲でよく見られる傾向をもとにした**大まかな目安**です（特定の調査の実測値ではありません）。「汎用の目安」は、ヒット曲の平均的なスペクトルの傾き（Pestana ら, AES 2013・2017）から作っています。
- 処理前の音が自動で B に入り、試聴音量が「ラウドネス一致」になります。音量差に惑わされずに音色と潰れ具合を聴き比べられます。「元の音に戻す」で戻せます。
- 処理後は自動で 2. の配信コーデックの確認も走り、変換後のピークを確かめられます。
- マスタリングでミックスの問題は直せません。最後は耳で判断してください。

## 自動で解析するもの・しないもの

- 読み込むと自動で解析：ラウドネス・ピーク・ダイナミクス（PLR・PSR・DR）・周波数バランス・ステレオ・BPM・キー・構成・公開前チェック・配信コーデックの確認（2. のチェックで切り替え可）
- 9. 音響・振動解析（騒音計・心理音響・次数解析・伝達関数など測定・工業向け）は、最初は隠しています。「9. を表示する」で出せて、どれも「計算」を押したときだけ動きます。

## 編集（10. 編集・書き出し）

- **基本編集**: 切り出し・削除・無音化・無音挿入、フェードイン/アウト、ゲイン、ピーク/ラウドネスのノーマライズ
- **書き出し・結合・分割**: 5. のマッチ EQ や 9. のフィルタを音に反映、WAV/FLAC 書き出し（タグ付き）、複数ファイルの結合、構成区間・マーカー・一定長・無音での分割（ZIP）
- **分離・修復・ピッチ/時間**: 元のツールの機能
- **コード譜・TAB 譜**: コード譜は小節をダブルクリックで書き換え、TAB 譜は「手で編集する」で自由に直して保存

編集した音は「元の音に戻す」で、編集前に戻せます。MP3 への書き出しはできません（WAV / FLAC）。

## 動作環境

PC 版の Chrome または Edge を推奨します。
