# 楽曲アナライザ

自分の楽曲ファイル（WAV / AIFF / FLAC / MP3 / Ogg / AAC など）を読み込んで、解析と編集をするブラウザツールです。インストールは不要で、音声はすべてPC内で処理されます（外部には送信されません）。

**使う: https://airman8787.github.io/music-analyzer/**

`index.html` をダウンロードして、ローカルで開いても同じように使えます。

元: [airman8787/tab-analyzer](https://github.com/airman8787/tab-analyzer)（MIT）。タブ録音を外し、ファイル専用にして編集機能を足しました。

## いちばん簡単な使い方（かんたん表示）

1. 曲ファイルを枠にドロップします。
2. 「おまかせで仕上げる」に、専門用語を使わない診断（音量・音割れ・迫力・音色・低音の広がり・高音の欠け）が出ます。
3. ジャンルを選んで「✨ 音を良くする」を押します。
4. 「▶ 仕上げた音」「▶ 元の音」で聴き比べます（音量をそろえて再生するので、公平に比べられます）。
5. 良ければ「💾 仕上げた音を保存」（ファイル名の末尾に `_master` が付きます）。

最初は「かんたん表示」で、診断・おまかせ・公開前チェックだけを表示します。1. の「くわしい表示」に切り替えると、すべての解析と、マスタリングの細かい設定（10.）が出ます。

## はじめかた

1. 「1. 読み込み」の枠に音声ファイルをドロップするか、「ファイルを選ぶ」で選びます。**何曲でもまとめて入れられます。**
   - 1 曲目が A として 2.〜10. に表示され、残りの曲も順番に自動で解析されて「曲リスト」に並びます（ラウドネス・ピーク・PLR・PSR・LRA・BPM・キー・チェック結果）。
   - リストの「A で表示」（または曲名のクリック）で、その曲の詳しい結果に切り替わります。
   - 「解析した曲を 8. に保存（音声つき）」にチェックすると、解析した曲が 8. の保存一覧にも入ります。一覧は CSV で保存できます。
2. 「2. 概要」と「3. 公開前チェック」で、音圧・ダイナミクス・周波数バランスなどの結果と対処のしかたを見ます。
3. 「4. 波形」はクリックで再生、ドラッグで範囲を選べます（選んだ範囲は、編集や書き出しの対象にできます）。

## アルバムとしてまとめて仕上げる（1. の曲リスト）

曲リストに入れた全曲に、10. の「おまかせマスタリング」と同じ仕上げをかけて、ZIP（FLAC 24bit / WAV 24bit / WAV 16bit）で保存します。ファイル名は `01_曲名_master.wav` のように曲順の番号付きです。

- 「全曲の音量をそろえる」（おすすめ）：まず各曲をジャンルの目安で仕上げ、いちばん小さく仕上がった曲（音質優先で止まった曲を含む）の音量に、0.5 dB 以上大きい曲を合わせて仕上げ直します。後から音量を下げるより、リミッターのかかりが浅くなるためです。
- 「各曲ともジャンルの目安に合わせる」：曲ごとに目安どおり仕上げます（音質優先で止まった曲は小さめになります）。
- 確認：60 秒の 3 曲（性格の違う曲）を EDM の目安で仕上げ、保存した ZIP を展開して計測すると、音量の差は最大 0.16 dB、トゥルーピークはすべて −1 dBTP 以下でした。

## A/B 比較（2曲を聴き比べる）

1. 「1. 読み込み」の曲リストで、比べたい曲の「B で比べる」を押します。最初に 2 曲だけまとめて入れたときは、自動で A と B に入ります。
2. 上のバーの ▶ / A / B ボタン、または `X` キーで切り替えます。
3. 公平に比べるときは、試聴音量を「ラウドネス一致」にしてください（大きい音のほうが良く聞こえやすいためです）。

- 切り替えても再生位置は同じままで、前後の無音をトリムした状態で頭がそろいます。ループ再生中も切り替えられます。
- B の再生中も波形に再生位置が出て、クリックするとその位置へ移動します。
- 上のバーに「B は A より -7.5 dB」のように音量差が出ます。
- B は保存されず、ページを閉じると消えます。残したい曲は、A として読み込んで「8. 保存して比較」で保存してください。

## おまかせマスタリング（かんたん表示の「音を良くする」／くわしい表示の 10. の最初のタブ）

ジャンルを選んで実行すると、曲全体に次の順で処理をかけます（くわしい表示では、各段のオン・オフと強さを変えられます）。

1. **オート EQ**：「ジャンルの目安」か「5. で選んだターゲット（好きな曲から作ったもの）」との音色の差を、約 1 オクターブで平滑化し、帯域を固定した幅の広い 5 バンド（90 Hz シェルフ・250 Hz・800 Hz・2.5 kHz・8 kHz シェルフ）の最小二乗で補正します（最大 ±3 dB × かかり具合）。曲のキーや楽器の音程による細かい山谷は追いません。20 Hz 以下の超低域カットもかけられます。
2. **低域のモノラル化**（自動：低音が左右に広がりすぎのときだけ）：サイドからゼロ位相の 4 次ローパス成分を引き、120 Hz 以下の左右差だけをなくします。上の帯域の位相とステレオ感は変わりません。
3. **耳に痛い瞬間を抑える**（試験的・既定はオフ）：4.2 kHz 付近が中域と比べて突出した瞬間だけ下げるダイナミック EQ。
4. **オートコンプ**：左右連動の RMS 型。しきい値は曲の大きい部分から自動で決め、そこで約 1.5 / 2.5 / 4 dB 圧縮します（弱め / ふつう / 強め）。
5. **リミッター**：4 倍オーバーサンプリングでピークを検出する先読みリミッターで、目標の統合ラウドネスに合わせます。最後に解析と同じ精密なトゥルーピークで確かめ、上限（既定 −1 dBTP）を超えていたら補正します。
6. **音質優先**（既定オン）：PSR（曲の大きい部分のピークと短時間ラウドネスの差）が 8 dB を割る手前で、音量を上げるのを止めます。止めたときは、その理由と止めた値を表示します。

| ジャンル | 目標 | コンプ | 音色の傾向（汎用の目安との差） |
|---|---|---|---|
| 配信向け | −14 LUFS | ふつう | なし |
| J-POP・ポップス | −9 LUFS | ふつう | 低域 +1・張り +0.5・高域 +1 dB |
| ロック・バンド | −9 LUFS | ふつう | 張り +1・高域 +0.5 dB |
| EDM・ダンス | −7.5 LUFS | 強め | 低域 +3・張り −0.5・高域 +1.5 dB |
| ヒップホップ・トラップ | −8 LUFS | ふつう | 低域 +3.5・高域 +0.5 dB |
| R&B・バラード | −11 LUFS | ふつう | 低域 +1.5・高域 +0.5 dB |
| アコースティック・弾き語り | −13 LUFS | 弱め | 低域 −1・高域 +0.5 dB |
| ジャズ | −14 LUFS | 弱め | 高域 −0.5 dB |
| クラシック・映画音楽 | −18 LUFS | なし | 高域 −1 dB |

- ジャンルの値は、市販曲でよく見られる傾向をもとにした**大まかな目安**です（特定の調査の実測値ではありません）。「汎用の目安」は、ヒット曲の平均的なスペクトルの傾き（Pestana ら, AES 2013・2017）から作っています。
- 処理前の音が自動で B に入り、試聴音量が「ラウドネス一致」になります。「元の音に戻す」で戻せます。かんたん表示で「もう一度仕上げる」を押すと、元の音からかけ直します（重ねがけしません）。
- マスタリングでミックスの問題は直せません。最後は耳で判断してください。

### 上級者向けの調整（くわしい表示の 10. →「上級者向けの調整」）

- **手動 EQ**：バンドごとに種類（ピーク・シェルフ・ハイパス・ローパス）・周波数・Q・ゲインと、かける対象（左右 / ミッド / サイド）を指定できます。「オート EQ の提案を表に入れる」で自動の提案から始めて細かく直せます。設定はブラウザに残ります。周波数特性のカーブを左右・ミッド・サイド別に表示します。
- **リニアフェーズ（ゼロ位相）**：各段を前向きと後ろ向きに通して位相のずれをなくします（書き出し前のオフライン処理なので可能）。打楽器の前に小さなプリリンギングが出ることがあります。
- **コンプの数値指定**：比率・圧縮量（曲の大きい部分での目標ゲインリダクション）・アタック・リリース。
- **リミッターの数値指定**：先読み・保持・リリース（最短〜最長）。
- **処理後のグラフ**：コンプとリミッターが「どこで、どれだけ抑えたか」の時間変化（50 ms ごと）と、処理前・処理後・目安の音色の重ね表示。

### 音質の検証（実測値）

処理の質は、テスト信号で数値を測って確かめています（実際の楽曲での聴感テストはまだ行っていません）。

| 項目 | 結果 |
|---|---|
| リミッター：正弦波を 6 dB 押し込んだときの THD+N | 25 Hz〜1 kHz で −129 dB 以下（改良前は 50 Hz で −36.8 dB） |
| コンプ：強め（4 dB 圧縮）の THD+N | 30〜37 Hz で −70 dB 以下、45〜63 Hz で −82 dB 以下、80 Hz 以上で −97 dB 以下（改良前は 40 Hz で −45 dB） |
| ラウドネスの合わせ込み | 目標との差 0.1 dB 以内（ミックス想定の合成信号、−9 / −14 LUFS） |
| トゥルーピーク | 上限 −1 dBTP を超えない（解析と同じ精密な方法で確認） |
| 低域のモノラル化 | サイドの 60 Hz を −62 dB まで除去、1 kHz のサイドとミッドは変化なし |
| リニアフェーズ EQ（1 kHz・+6 dB） | 中心 +6.000 dB、位相 0.000°（100 Hz〜8 kHz）、インパルス応答の左右差 1.9×10⁻⁹ |
| M/S EQ（サイドに +6 dB） | ミッドだけの音は変化 0（ビット単位で同じ）、サイドだけの音は +6.00 dB |

## トゥルーピークの測り方

BS.1770 の 4 倍オーバーサンプリングでピークのありそうな位置を探し、その近くを ±128 タップのカイザー窓 sinc で 1/16 サンプル刻み（＋放物線補間）まで細かく補間して求めます。4 倍の格子では高域の強い音で読み落とすためです。

- 以前の版は、候補を 200000 か所で打ち切っていたこと、また強くクリップした広帯域ノイズでは BS.1770 の 4 倍 FIR が想定より低く読むことから、最大 0.47 dB 読み落とすことがありました（合成信号での確認）。
- 今の版は打ち切りをなくし、候補の幅を広げたうえで、まず 1/4 サンプル刻みの 3 点だけを精密に計算し、1/cos(π/8) を掛けても今の最大に届かない位置は細かい計算を省いて速くしています。
- 合成信号 400 通り（ナイキスト付近の正弦波・ホワイトノイズ・クリップしたノイズ・矩形波・インパルス・チャープ、半数はリミッター通過）で、全数計算に対して読み落としがないことを確認しました。
- 速さ（ブラウザ・1 チャンネル）：リミッターで強く潰した 3 分の音で 6.5 秒 → 2.8 秒、60 秒のマスター音源で 0.94 秒 → 0.79 秒。

## 書き出し

WAV 24bit / WAV 16bit（TPDF ディザ・CD 向け）/ WAV 32bit float / FLAC 24bit / FLAC 16bit（ディザ）。FLAC はビット単位で WAV と同じ値になることを確認しています。

## 自動で解析するもの・しないもの

- 読み込むと自動で解析：ラウドネス・ピーク・ダイナミクス（PLR・PSR・DR）・周波数バランス・ステレオ・BPM・キー・構成・公開前チェック・配信コーデックの確認（くわしい表示のときだけ。2. のチェックで切り替え可）
- 9. 音響・振動解析（騒音計・心理音響・次数解析・伝達関数など測定・工業向け）は、最初は隠しています。「9. を表示する」で出せて、どれも「計算」を押したときだけ動きます。

## 編集（10. 編集・書き出し）

- **基本編集**: 切り出し・削除・無音化・無音挿入、フェードイン/アウト、ゲイン、ピーク/ラウドネスのノーマライズ
- **書き出し・結合・分割**: 5. のマッチ EQ や 9. のフィルタを音に反映、WAV/FLAC 書き出し（タグ付き）、複数ファイルの結合、構成区間・マーカー・一定長・無音での分割（ZIP）
- **分離・修復・ピッチ/時間**: 元のツールの機能
- **コード譜・TAB 譜**: コード譜は小節をダブルクリックで書き換え、TAB 譜は「手で編集する」で自由に直して保存

編集した音は「元の音に戻す」で、編集前に戻せます。MP3 への書き出しはできません（WAV / FLAC）。

## 動作環境

PC 版の Chrome または Edge を推奨します。
